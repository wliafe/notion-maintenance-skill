# 查找「使用说明」

默认同步场景（仅点名本技能、无其它提示词）先按 [默认：从对话更新工作台](default-workbench-sync.md) 完成对话材料收集，再按本文查找「使用说明」。

本参考只约定**如何找到**维护手册章节。章节标题统一为 **「使用说明」**。不要在本文件或技能中写入任何具体维护规则、页面 ID 或固定 URL。

## 入口页

1. 用 Notion MCP 的搜索能力，按标题关键词查找入口，优先尝试「工作台」；用户点名了页面或工作区入口时，以用户指定为准。
2. 打开最相关的入口页并完整读取。入口页上的 **「使用说明」** 通常给出阅读顺序、内容归属与对其他会话的适用条件。
3. 从入口页的链接或子页面进入本次任务对应的分区（例如项目、工作方式、知识库等），不要凭记忆跳转到未核验的页面。

## 分区与分类页

1. 在即将修改的分区页上查找标题为 **「使用说明」** 的章节（常见为二级标题）。
2. 文中若写明“先读某上级页的使用说明”，先 `fetch` 上级页对应章节，再读本区「使用说明」。
3. 分类入口页可能只有简短「使用说明」并指向上级；仍须读完本页要求，再进入具体条目页。
4. 条目正文本身不是「使用说明」。改条目时，以所属分区/知识库/工作台的「使用说明」为准。

## 找不到时

按顺序排查，并如实报告：

1. 搜索词是否过窄或过宽；尝试用户提到的入口名、分区名。
2. 页面是否存在同名章节但层级不同；通读页面大纲，确认是否有「使用说明」。
3. 当前 Notion 连接是否指向正确工作区；工具报错时先处理连接问题。

仍找不到时，停止修改内容，请用户指出入口页或确认章节标题；不要用旧称谓猜测，也不要用技能内嵌的假规则代替手册。

## 与技能的边界

- 「使用说明」的正文可以随时在 Notion 中修改；技能与本参考**不**同步抄写这些正文。
- 若用户把手册章节改成其他名字，需要同步更新本约定；在约定更新前，仍只认「使用说明」。
